Featured · game backend

Game Leaderboard Service

Leaderboard backend for multiplayer games. Match results come in through a REST API, flow through Kafka, and rankings are served from Redis sorted sets.

  • Idempotent consumer: the match id and the points are written in one transaction, so a duplicate Kafka delivery never double-counts.
  • Concurrent updates use INSERT … ON CONFLICT; failing messages go to a dead-letter topic.
  • RFC 9457 errors, Prometheus metrics, 18 JUnit + Testcontainers tests in CI.
